Jenkins DevSecOps Pipeline

Every change passes code quality analysis and image vulnerability scanning before an image reaches the registry and the cluster.

  • SonarQube performs static code analysis
  • Trivy scans the built container image
  • Scanned images are pushed to Amazon ECR
  • The final stage deploys the application to Amazon EKS

  2. Application Load BalancerAWS Load Balancer Controller

EKS Deployment

Traffic reaches pods through an Ingress managed by the AWS Load Balancer Controller; images come from ECR and releases are packaged with Helm.

  • Ingress and Service route traffic to pods
  • Deployments run on an EKS node group
  • ConfigMaps and Secrets carry configuration
  • Horizontal Pod Autoscaler scales replicas
